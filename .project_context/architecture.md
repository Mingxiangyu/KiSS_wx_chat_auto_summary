# 项目架构文档

## 系统概述
微信聊天记录自动总结系统，基于Google Gemini API实现智能分析和HTML日报生成。

## 核心架构组件

### 1. 数据获取层
- **chatlog服务**: 本地服务，负责微信聊天记录的提取和API接口提供
- **数据接口**: RESTful API，提供聊天记录查询功能

### 2. AI处理层
- **Gemini API集成**: 使用Google Generative AI进行内容分析
- **模型配置**: 支持多种Gemini模型，默认使用`gemini-2.5-flash-preview-05-20`

### 3. Token计算架构 ⭐️ (重要更新)
- **统一计算函数**: `count_tokens_with_config` 确保本地计算与API调用一致性
- **全局配置参数**:
  - `GENERATION_CONFIG`: 标准化生成参数(temperature, top_p, top_k, max_output_tokens)
  - `SAFETY_SETTINGS`: 标准化安全设置(4个官方标准安全类别配置)
- **智能回退机制**:
  1. 优先使用配置参数计算token
  2. 回退到纯文本计算 + 1.5倍经验系数补偿
  3. 完整的错误处理和日志记录
- **一致性保证**: 所有token计算使用相同配置，消除本地预估与API实际消耗的差异

### 4. 安全设置架构 ⭐️ (重要修复 - 2025-01-25)
- **标准化安全配置**: 使用4个官方标准安全类别，设置为BLOCK_NONE最宽松阈值
  - `HARM_CATEGORY_HARASSMENT`
  - `HARM_CATEGORY_HATE_SPEECH`
  - `HARM_CATEGORY_SEXUALLY_EXPLICIT`
  - `HARM_CATEGORY_DANGEROUS_CONTENT`
- **配置验证机制**: 启动时自动验证安全类别名称的正确性
- **finish_reason处理**: 完善的响应状态检查和错误诊断机制
- **问题解决**: 修复了finish_reason=2安全过滤器误判问题，解决无效类别名称导致的配置失效

### 4. 内容处理层
- **智能分片**: 基于token限制自动分割长聊天记录
- **二分查找优化**: 高效确定最优分片大小
- **Prompt模板**: 可配置的分析提示词模板

### 5. 输出生成层
- **HTML生成**: 结构化的日报HTML输出
- **多格式支持**: HTML、PNG图片、URL发布
- **样式定制**: 可配置的视觉样式和布局

## 关键设计决策

### Token计算一致性 (ADR-001)
**问题**: 本地token计算与API实际消耗不一致，导致超限错误
**决策**: 实施统一配置参数法
**理由**: 
- 确保本地预估准确性
- 减少API调用失败
- 提供智能回退保护
**影响**: 显著提升系统稳定性和token使用效率

### 智能分片策略 (ADR-002)
**问题**: 长聊天记录超过模型输入限制
**决策**: 基于token的二分查找分片
**理由**: 
- 最大化每个片段的内容量
- 避免简单字符分割的不准确性
- 保持上下文完整性

### 流式响应处理 (ADR-003)
**问题**: 大内容生成时用户体验差
**决策**: 启用流式传输和进度显示
**理由**: 
- 实时反馈生成进度
- 提升用户体验
- 支持长内容生成
